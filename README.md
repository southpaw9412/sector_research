⚛️ Sovereign Sector Intelligence Hub (v4.0)

A professional-grade, high-density investment research terminal designed for collaborative sector analysis. This Single-Page Application (SPA) transforms a standard Google Sheet into a live institutional dashboard, featuring real-time data visualization and deep-research capabilities powered by the Gemini 2.5 Flash API.

🚀 Overview

The Sovereign Sector Hub is built for research pairs who need to track multiple market sectors (Quantum Computing, Precious Metals, Next-Gen Energy, etc.) with the precision of an equity research firm.

By utilizing Google Sheets as a headless CMS, you can update data collaboratively in a spreadsheet and see those changes reflected instantly in a stylish, interactive UI.

Key Features

Live Google Sheets Sync: Connects to any Google Sheet published as a CSV for real-time data updates.

Multi-Sector Navigation: Effortlessly switch between 10+ research sectors via a sidebar menu.

AI Research Auditor: Integrated Gemini 2.5 Flash API allows you to highlight any term, ticker, or metric to receive an instant AI-generated technical audit.

Institutional Visualizations: Custom Chart.js implementations for Valuation (EV/Revenue) and Competitive Moat (Fidelity vs. Scale).

Zero-Asset Architecture: Built entirely with HTML, Tailwind CSS, and Canvas. No SVG or external image dependencies.

🛠️ Installation & Setup

1. The Database (Google Sheets)

To bootstrap your research database:

Create a new Google Sheet.

Go to Extensions > Apps Script.

Paste the Bootstrap Script (provided in the project files) into Code.gs and run setupResearchSheet. This will build your 10-sector infrastructure.

Go to File > Share > Publish to web.

Select Entire Document and Comma-separated values (.csv).

Copy the generated URL.

2. Deployment (GitHub Pages)

Fork or clone this repository.

Upload the index.html file.

Go to Settings > Pages in your GitHub repository.

Under Build and deployment, set the source to Deploy from a branch and select main.

Your dashboard is now live at https://<your-username>.github.io/<repo-name>/.

3. Activation

Open your live URL.

Paste your Google Sheet CSV URL into the sidebar.

Enter your Gemini API Key (obtainable from aistudio.google.com).

Click Sync Master Sheet.

🧠 Using the AI Auditor

The hub is designed for "Concept Auditing." If your partner enters a metric or term you are unfamiliar with (e.g., “Coherence Time” or “SBC Dilution”):

Highlight the text with your cursor.

Click the floating ✨ AI Audit button.

The Research Terminal sidebar will open, providing a concise investment-focused explanation of the concept.

📊 Technical Architecture

Frontend: HTML5, Tailwind CSS (CDN), Chart.js (Canvas-rendered).

Backend: Google Sheets (CSV Engine).

AI: Google Gemini 2.5 Flash API.

Data Flow:
Google Sheet (Editor) ➔ Published CSV ➔ SPA (JavaScript Fetch) ➔ Chart.js/DOM Update.
